## ASSEMBLY ORDER

Build the prompt in this order. Each element is separated by a comma.

1. **Subject + identity** — who/what is in this image
2. **Pose / shot type** — how they are framed
3. **Location** — where, in prompt-ready language
4. **Lighting** — lighting preset fragment
5. **Mood** — emotional atmosphere
6. **Style + quality** — style core + base quality block
7. **Technical flags** — `--ar` `--v` `--q` `--s` (and `--no` if needed)
